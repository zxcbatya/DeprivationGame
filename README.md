# 🎮 DeprivationGame

_Игровой проект с фокусом на систематизацию разработки_

---

## 📌 Основные правила
- **Главная ветка** `main`  
  ▶️ Коммиты только от меня  
  ⚠️ Все изменения через Pull Request  
- **Ветка разработки** `modelers`  
  ▶️ Ваши коммиты только сюда  
  ▶️ Регулярно синхронизируйте с `main` (rebase)

---

## 🔧 Правила работы с Blueprints
1. **Группировка элементов**  
   🧩 Все переменные/объекты/компоненты должны быть логически сгруппированы
2. **Структура проекта**  
   🗄️ Четкая иерархия папок:  
/Assets
/Scripts
/Models
/Materials
/Prefabs

3. **Принцип KISS**  
✨ Избегайте избыточной сложности:  
- Минимум зависимостей
- Читаемые названия переменных
- Комментарии для неочевидных решений
